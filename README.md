An ad-hoc collection of Linux command line problems that have been used
by Ian Abbott (ija) to test various aspects of Belltech dbPOD protocol.

They are a bit of a random assortment, and not particularly elegant,
with random changes to their source code to tweak the way they configure
the sequence table entries.

For `HOST` and `PORT` in the usage, `HOST` is the IP address of the
dbPOD and `PORT` is the TCP port number, which should be set to 6000.
